# 安装

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 游戏版本 | 0.46 |
| 前置模组 | 无 |
| 运行库 | 无（Harmony 由游戏模组加载器提供） |

## 安装步骤

1. 关闭游戏。
2. 打开游戏根目录下的 `Mods` 文件夹。
3. 将模组文件夹完整复制进去，文件夹名称保持为 `更聪明的交易`。
4. 确认文件夹内包含以下内容：

```
更聪明的交易/
├─ manifest.xml
├─ SmarterTrading.dll
└─ Localization/
   ├─ zh.csv
   └─ en.csv
```

5. 启动游戏，在模组列表中勾选「更聪明的交易」并应用。

**〔图片 `images/04-folder.png`〕** 安装完成后的模组文件夹结构，标注 `manifest.xml`、`SmarterTrading.dll` 与 `Localization` 三项必需内容。

## 更新

1. 关闭游戏。
2. 用新版本覆盖 `SmarterTrading.dll` 与 `manifest.xml`。
3. 启动游戏。已保存的配置会自动沿用，无需重新设置。

模组文件夹内以点开头的目录（如 `.build`）为开发与构建目录，不参与游戏加载，可整体删除后不影响运行。

## 卸载

1. 关闭游戏。
2. 删除 `Mods/更聪明的交易` 文件夹。
3. 如需清除配置，同时删除游戏配置目录中该模组的设置文件。

存档不包含模组数据，卸载后存档可正常读取。
