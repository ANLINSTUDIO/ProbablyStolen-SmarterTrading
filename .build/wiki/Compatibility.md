# 兼容性

## 兼容范围

| 项目 | 状态 |
| --- | --- |
| 游戏版本 0.46 | 支持 |
| 存档 | 不写入模组数据，卸载后存档可正常读取 |
| 其他模组的配置 | 使用独立配置段，不与其他模组共用键名 |
| 界面与布局 | 不修改原有界面，仅在鼠标旁提示中追加内容 |

## 作用范围

本模组仅介入以下环节：

- 交易收尾对话的选择依据；
- 顾客所有、尚未购入的液体容器的交互判定；
- 灌装完成后的结算与顾客预算补足；
- 拖拽提示中的金额明细。

不涉及物品生成、价格表改写、经济参数调整、存档序列化。

## 潜在冲突

同类模组同时修改以下环节时可能出现行为不一致，建议只保留一个：

| 环节 | 可能表现 |
| --- | --- |
| 交易收尾对话改写 | 对话选择结果取决于后加载的模组 |
| 顾客容器交互放行 | 目标判定被覆盖后，灌装提示可能不出现或重复 |
| 售出结算改写 | 灌装金额与提示不一致 |

出现上述现象时，先单独启用本模组确认效果，再逐个启用其他模组定位冲突源。

## 已知限制

- 酒类容器不参与灌装；
- 顾客预算为零时不允许灌装；
- 仅处理柜台上的顾客容器，非柜台位置不生效；
- 顾客未表达购买水的意向时不提供灌装。
