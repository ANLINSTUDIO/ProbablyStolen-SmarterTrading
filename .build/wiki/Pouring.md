# 灌装操作

顾客携带液体容器购买水时，可直接把玩家的水灌入其容器，无需买下容器再整瓶售出。

## 操作步骤

1. 接待的一位顾客表达购买水的意向，其自带容器已放置在柜台上；
2. 从货架或库存中拖动玩家的水容器；
3. 将水容器拖到顾客的容器上，鼠标旁出现灌装提示；
4. 松开鼠标完成灌装，交易按水价结算。

**〔图片 `images/02-pour-drag.png`〕** 第 3 步的拖拽界面：目标容器高亮，提示首行为「对〔容器〕使用〔水源〕 并卖出」，下方为价格明细。

**〔图片 `images/06-pour-done.png`〕** 灌装完成后：顾客容器水量已更新，成交金额出现在交易面板。

## 可用条件

以下条件全部满足时才能灌装，任一不满足则提示不显示、交互不生效：

| 条件 | 说明 |
| --- | --- |
| 目标是液体容器 | 顾客的容器需为液体容器，酒类容器不在范围内 |
| 目标归顾客所有且未购入 | 容器属于顾客、仍在柜台上、尚未被买下 |
| 目标位于柜台 | 容器摆放在店铺柜台上 |
| 水源为玩家自有 | 水源必须是玩家拥有的液体容器 |
| 水源有余水 | 水源不为空 |
| 目标未满 | 顾客容器尚有空余容积 |
| 顾客有意购买 | 顾客确实想买该水质的水 |
| 顾客预算不为零 | 预算为零时不进行灌装 |
| 交易进行中 | 当前有正在接待的顾客，且未处于结算完成、拘捕或枪战状态 |

## 灌装量

由双方容器决定，与直接售水一致：

- 不超过目标容器的剩余容积；
- 不超过水源容器内的剩余水量；
- 实际灌入量以游戏原有水系流程计算，容器贴图与水质特征同步更新。

**〔图片 `images/07-volume.png`〕** 相同水源分别灌入不同容积容器时的灌注量对照。

## 计价与归属

- 仅对灌入的水计价，容器本体不计入成交金额；
- 价格与正常售出一致，含品相、市场事件、零售加价与小费，详见 [计价说明](Pricing)；
- 容器自始至终归顾客所有，不进入买卖列表；
- 灌装后若顾客买下该容器，预算按买回价全额恢复。

## 不适用的情形

- 酒类容器之间的灌注；
- 顾客容器已被买下（此时为玩家自有物品，走常规操作）；
- 顾客未表达购买水的意向；
- 顾客预算为零；
- 容器不在柜台上。
