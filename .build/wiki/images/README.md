# 图片占位清单

本目录用于存放文档配图。文档中的图片位置已全部标出，实际文件尚未提供，替换时保持文件名一致即可。

## 命名规则

- 序号 `NN-` 对应文档出现顺序；
- 小写英文，短横线分词；
- PNG 格式，宽度建议 1600px，界面截图保留原始 UI 比例。
