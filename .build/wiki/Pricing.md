# 计价说明

灌装按「把水正常卖给眼前这位顾客」的价格结算，与整瓶售出的价签同源，不另设折扣或加成。

## 价格构成

价格由三个层级依次计算，与议价平板的显示顺序一致。

| 层级 | 内容 | 示例 |
| --- | --- | --- |
| 品相 | 水的纯净度与品质特性，按百分比加成到基础值 | 纯净水、含杂质水 |
| 市场与商人 | 市场事件与商人相关加成：零售加价、小费、市场短缺、成瘾相关惩罚等 | 缺水事件 +35%、零售加价 15%、小费 |
| 最终系数 | 上述结果的整体倍率，由游戏按交易状态统一计算 | 议价结果修正 |

基础值为每升水 40 单位值。品相加成作用于基础值，市场加成在其结果上叠加，最终系数整体相乘，容器自身价值单独计入。

## 结算规则

- 结算金额取「灌装前后同一容器的议价差额」，因此只包含本次灌入的水，容器本体价值自动抵消；
- 灌装产生的市场加成同步写入容器的估价；
- 因此「本次灌装收费 + 容器自身价值」与顾客买回该容器的价格相等，反复灌装、买回、再售出不会产生价差；
- 顾客预算按游戏既定折算比例扣减，买回灌装容器时按买回价全额补足差额。

## 提示中的字段

| 字段 | 含义 |
| --- | --- |
| 价格 `x/升` | 当前水质的每升结算价 |
| 还能灌 `x 升` ≈ `金额` | 按容器剩余容积计算的本次结算金额；容器已满时显示「容器已满」 |
| 本次灌 `x 升` ≈ `金额` | 持有水源时的实际可灌量与金额 |
| 品相 | 生效中的品相特性列表 |
| 市场与商人 | 生效中的市场与商人加成列表 |
| 顾客预算 | 顾客当前可用预算，不足时以警示色显示 |
| 预计卖出 | 本次灌装的结算总额 |

字段名称与议价平板保持一致，价格单位与游戏内货币显示一致。

## 收支关系

设单升结算价为 `P`、本次灌装量为 `V` 升、容器自身估价为 `C`，则：

| 项目 | 计算 |
| --- | --- |
| 本次灌装收费 | `P × V` |
| 顾客买回整只容器 | `P × V + C` |
| 玩家净收支 | 收费 − 买回 = `−C` |

灌装收费与容器价值之和等于买回价，交易只按容器本身的价值结算一次，反复倒手不产生差额。

> `P` 随水质品相、市场事件与商人加成浮动，`C` 随容器余量变化，两者均以提示中显示的数值为准。
