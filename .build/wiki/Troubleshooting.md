# 故障排查

## 日志位置

模组运行信息写入游戏日志：

```
%USERPROFILE%\AppData\LocalLow\Questing Goose Studio\Probably Stolen\GameLog_*.txt
```

检索关键字 `[更聪明的交易]` 可定位全部相关记录。开启「详细日志」后会输出判定细节。

## 常见现象

| 现象 | 可能原因 | 处理方式 |
| --- | --- | --- |
| 拖拽水容器无提示 | 条件不满足：顾客无购买意向、容器不在柜台、容器已满、水源已空、顾客预算为零 | 逐项核对 [可用条件](Pouring#可用条件) |
| 提示出现但松开无效 | 目标容器已被买下或不在柜台 | 确认容器仍归顾客所有 |
| 灌装成功但未计入成交 | 顾客未完成购买流程 | 等待本笔交易结算，金额在面板中显示 |
| 顾客预算未恢复 | 买回的并非灌装过的容器 | 预算补足仅作用于经本模组灌装的容器 |
| 收尾台词未变化 | 本次来访尚未成交、顾客非预算型、或该功能已关闭 | 确认已成交过商品并检查配置 |
| 模组列表不显示 | 文件夹名称或 `manifest.xml` 缺失 | 核对 [安装](Installation#安装步骤) 的目录结构 |
| 模组被禁用且无法重新启用 | 模组根目录存在可执行文件（编译产物、脚本等） | 清除根目录下多余文件，构建目录应置于以点开头的文件夹内 |

## 判定依据

开启「详细日志」后，日志中会记录：

- 本次来访的成交均价与顾客余额；
- 是否触发收尾台词替换；
- 灌装的容器、水量、结算金额与顾客预算变化。

## 报告问题

反馈时请附上：

1. 模组版本与游戏版本；
2. 复现步骤；
3. 对应时间段的日志片段；
4. 已安装的其他模组列表。
