# 功能总览

本模组包含四项功能，均作用于原版交易流程内部，不新增界面、不改动存档结构。

## 成交收尾判定

顾客购买商品后，游戏会判断其是否继续选购。原版依据固定阈值（余额低于 10 信用点）决定是否结束交易，低于该值才会改用收尾台词。

本模组将判断依据改为本次来访的实际成交均价：

| 条件 | 交易结束时的对话 |
| --- | --- |
| 余额 ≥ 本次成交均价 | 继续询问是否还有别的商品 |
| 余额 < 本次成交均价 | 使用收尾台词结束交易 |
| 本次来访尚未成交 | 保持原版行为 |

成交均价取本次来访中玩家售出商品的标准售价算术平均值。仅对启用预算系统的顾客生效，非预算型顾客不受影响。

**〔图片 `images/01-budget-dialog.png`〕** 左侧为余额充足时的追问对话，右侧为余额低于成交均价时的收尾对话，附对话文本对照标注。

## 顾客容器现场灌装

顾客携带容器购买水时，柜台上的空容器可以承接玩家自有的水。灌装量、水质、价值更新均沿用游戏原有流程，本模组仅放行交互判定并按水计价。

适用条件、操作步骤与限制见 [灌装操作](Pouring)。

**〔图片 `images/02-pour-drag.png`〕** 玩家水容器拖向顾客空容器时的目标高亮状态。

## 灌装报价提示

拖动水容器对准顾客容器时，鼠标旁提示按议价平板的样式分条列出本次交易明细：

- 价格：每升价格与可灌装量对应的总价；
- 品相：容器内水的品相构成；
- 市场与商人：当前生效的市场事件与商人相关加成，如零售加价、小费、市场短缺；
- 顾客预算：顾客当前可用预算，不足以支付时以警示色显示；
- 预计卖出：本次灌装的结算金额。

提示仅在满足灌装条件时出现，条件不满足时不显示金额。

**〔图片 `images/03-tooltip-breakdown.png`〕** 完整的五段式提示明细，标注各段名称。

## 预算恢复

顾客将灌装过的容器买回时，其预算按买回价全额恢复。原版对售出商品按既定折算比例扣减顾客预算，本模组针对灌装容器补齐差额，使顾客不会因一次灌装丢失预算额度。

该处理仅作用于经本模组灌装过的容器，不影响其他商品的预算结算。

**〔图片 `images/05-budget-restore.png`〕** 买回灌装容器前后顾客预算的变化，标注补足金额。
