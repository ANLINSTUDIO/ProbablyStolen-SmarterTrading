# 更聪明的交易 · Smarter Trading

面向《Probably Stolen》的交易体验增强模组。在保持原版规则与界面的前提下，让成交判断依据实际成交额，并允许玩家直接把水灌进顾客自带的容器。

| 项目 | 内容 |
| --- | --- |
| 模组版本 | 1.0.8 |
| 适配游戏版本 | 0.46 |
| 前置依赖 | 无 |
| 作者 | 遇欲 |
| 模组 ID | `smarter_trading` |

## 简介

游戏内的顾客按预算购买商品。交易收尾的判断依据为固定阈值：余额高于该值时，即使不足以购买下一件商品，顾客仍会继续询问是否还有别的。同时，顾客自带的容器无法与玩家的水容器直接交互，液体交易只能以整只容器完成。

本模组针对这两处体验作补充：收尾对话改以本次成交均价为判断依据；顾客摆放在柜台上的空容器可以承接玩家自有的水，按正常售价结算，容器归属保持不变。

## 功能

| 功能 | 效果 |
| --- | --- |
| 成交收尾判定 | 顾客剩余预算低于本次成交均价时，交易以原版收尾台词结束，不再追问「就这些吗？」 |
| 顾客容器灌装 | 将水直接灌入顾客摆在柜台上的空容器，仅按水计价，容器始终归顾客 |
| 灌装报价提示 | 拖动水容器对准顾客容器时，提示按议价平板样式分条列出价格、品相、市场加成、顾客预算与预计卖出 |
| 预算恢复 | 顾客买回灌装过的容器时，其预算按买回价全额恢复 |

### 成交收尾

顾客剩余预算不足以再购买一件同等价位的商品时，交易会以「成交。」「我要的就是这个。」「下次见。」等收尾台词结束。判断基准为本次来访中所有已成交商品的标准售价均值；本次来访尚未成交时，保持原版行为。

**〔图片 `images/01-budget-dialog.png`〕** 顾客余额不足时的成交收尾对话，与余额充足时继续询问的对话作对照。

### 现场灌装

当顾客有意购买水时，可将其摆在柜台上的空容器作为灌注目标。可灌注的对象与限制：

- 目标必须是顾客所有、尚未购入的液体容器，摆放在店铺柜台上；
- 水源必须是玩家自有的液体容器，且存有余水；
- 灌装量由双方容器容积与现有水量决定，与直接售水一致；
- 酒类容器不参与此功能；
- 顾客需确实有购买该水质的意向，且预算不为零。

灌装完成后按正常售出价格结算，容器本体不计价、不进入交易，始终归顾客所有。

**〔图片 `images/02-pour-drag.png`〕** 拖动水容器对准顾客空容器时的目标高亮与拖拽提示。

**〔图片 `images/03-tooltip-breakdown.png`〕** 灌装提示的完整分条明细：价格、品相、市场与商人、顾客预算、预计卖出。

## 价格

灌装价格与正常售出完全一致：以水质与容器内水量为基础，叠加品相、市场事件（如缺水）、零售加价与小费，并计入容器自身的估价。因此「灌装收费 + 容器价值」与顾客买回该容器的价格相等，反复倒手不会产生价差。完整计价构成见 [计价说明](.build/wiki/Pricing.md)。

## 安装

1. 将模组文件夹放入游戏目录下的 `Mods` 文件夹；
2. 确认文件夹内包含 `manifest.xml`、`SmarterTrading.dll` 与 `Localization` 目录；
3. 启动游戏，在模组列表中启用「更聪明的交易」。

后续更新只需覆盖 `SmarterTrading.dll` 与 `manifest.xml`。

**〔图片 `images/04-folder.png`〕** 安装完成后的模组文件夹结构示意。

## 配置

游戏内模组设置页提供以下选项：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 启用「更聪明的交易」 | 开 | 总开关，关闭后全部功能失效 |
| 预算不足时不再追问「就这些吗」 | 开 | 控制成交收尾判定 |
| 允许把水灌进顾客自带的容器 | 开 | 控制现场灌装与灌装提示 |
| 详细日志 | 关 | 输出判定细节，用于排查问题 |

## 兼容性

本模组仅修改交易收尾对话的判定来源与顾客容器的灌注判定，不改动界面布局、存档结构与其他模组的配置。与其他交易类模组的潜在冲突见 [兼容性说明](.build/wiki/Compatibility.md)。
